# 新股速读 · xingu-speed-read

把一只 A 股新股（招股书要点 + 板块规则 + 产业链地图 + 可比公司 + 中性风险）自动扒成一张**黑金风速读卡**的工具。

定位：**中性事实型工具**，不荐股、不打分、不预测涨跌。适合小红书「新股速读」内容线。

来自 Coze 金融工具调研（Part 2）：在 ~80 个金融工具里，「新股专家」是唯一的蓝海内容线——Coze 无同类中性内容，且完美贴合「AI 辅助投资 / 持仓体检」调性。

## 速读卡结构（5 段纯客观数据）

1. **事实卡** — 代码、上市日、发行价、首日表现、募资额、板块、一句话定位
2. **板块规则区分** — 左侧 SVG K 线示意（前 5 日无涨跌幅冲高回落 + 30%/60% 停牌标注 + 第 6 日起 ±20% 通道），右侧三要点
3. **产业链地图** — 三栏：上游（设备材料，绿描边）→ 中游（发行人自身，金色芯片装饰）→ 下游（封测模组，灰描边）
4. **可比公司对照** — 客观定位已上市可比公司，不打分不排座次
5. **中性风险提示** — 高估值溢价 / 累计未弥补亏损 / 新股前 N 日波动 / 题材跟风区分

> ⚠️ **产物边界**：速读卡只含以上 5 段纯客观数据。蹭热度话术 / 评论区钩子 / 工具属性口吻一律归「发帖文案层」，由人粘贴到小红书，绝不写进生成的 HTML。

## 用法

```bash
python3 scripts/gen_xg.py examples/data.json output-demo.html
```

把目标新股整理成 `data.json`（字段见 `references/method.md`），跑一行即出黑金速读卡 HTML。

## 文件

- `SKILL.md` — skill 定义与触发场景
- `scripts/gen_xg.py` — 读 data.json 生成黑金速读 HTML（v2 视觉）
- `references/method.md` — 字段表 + 文案范式 + 黑金 CSS tokens
- `output-demo.html` — 长鑫科技（688825）首篇样例
- `examples/data.json` — 样例数据（长鑫）
